## 机房 IP、动态住宅、静态住宅：平台看到的到底是什么

搜「日本住宅IP」的人多半已经踩过一次坑：买了个几十块的日本 VPS，IP 归属地写着东京，结果 TikTok 后台地区乱跳、Netflix 提示内容不可用、注册 ChatGPT 直接触发风控。问题不在服务器位置，在 ASN。

机房 IP 由 IDC 或云厂商分配，通常整段批发，延迟低、速度快，但属性一眼可辨。IPinfo、IP2Location 这类工具会直接标成 Hosting 或 Datacenter，Scamalytics 的风险分也偏高。拿它建站、跑测试没问题，做账号矩阵基本等于自曝。

动态住宅 IP 来自真实家庭宽带，风控识别度低很多，代价是 IP 会周期性更换，常见做法是每天凌晨换一个新地址。采集数据、批量注册、短期任务用它很合适。但账号运营是另一回事：IP 一变，账号绑定的「身份」跟着变，平台看到的是同一个账号每天从不同家庭宽带登录。

静态住宅 IP 是这两者的交集：真实家宽属性加 IP 长期固定。平台查过来，看到的是一个东京居民用本地宽带上网，而且一直用同一条线。做日区 TikTok 长期运营、维护亚马逊日本站店铺、稳定解锁日区流媒体，需要的是这一种。

| IP 类型 | 平台风控视角 | IP 是否固定 | 适合 |
| --- | --- | --- | --- |
| 机房 IP | Hosting / Datacenter，风险分偏高 | 固定 | 建站、测试、非敏感业务 |
| 动态住宅 IP | 真实家宽，但来源在变 | 每日或按需更换 | 数据采集、短期注册、批量任务 |
| 静态住宅 IP | 真实家宽，长期同一地址 | 长期固定 | 账号运营、电商店铺、流媒体 |

判断手里这个 IP 属于哪一类，不需要什么特殊工具：IPinfo 看 ASN 是不是归属运营商、类型是不是 Residential ISP，Scamalytics 看风险分，两项都对得上才算住宅 IP；显示 Hosting 就是机房 IP，没有第二种解释。

顺带说一句运营商的选择。中文圈里流传一种说法，认为 SoftBank 在东京都市圈覆盖广、住宅用户基数大、IP 段被平台识别的历史相对干净，NTT Docomo 商用段偏多，KDDI 可供商业采购的住宅资源较少。这是从业者的经验判断，没有官方数据支撑，只能当参考。丽萨主机走的是另一条路：IIJ 是日本老牌互联网服务提供商，AS2497，官方把这条线定位成「双 ISP 原生住宅」，卖点是 IP 属性而不是某一家运营商的标签。

## 先想清楚：你要的是一个代理 IP，还是一台能装软件的机器

在掏钱之前，有个更前置的问题值得花两分钟：你需要的形态是代理，还是 VPS。

代理服务商卖的是通道。以 IPdodo 为例，日本静态住宅 IP **¥78/个/月**，不限流量，支持 http/https/socks5，资源采自日本本地运营商；面向 TikTok 账号运营的「运营网络」**¥158/月 起**，独享 IP、独享带宽不限流量，官方说可运营 1 到 3 个账号。这类产品的特点是开箱即用，浏览器、指纹浏览器、手机、路由器都能接，不需要你懂 Linux。

代价是你能拿到的只有一个网络出口。想在上面跑个自动化脚本、挂个中转服务、装个指纹浏览器再配代理链，就得看服务商给不给这个权限。

VPS 卖的是整台机器。丽萨主机 169 元/月的 ISP 基础版，给的是 1 核 1G、20G NVMe、300Mbps 带宽、每月 3000GB 流量的完整 KVM 虚拟机，带 1 个 IPv4，能装 Windows，能自己配环境、开端口、架中转。住宅 IP 是这台机器自带的属性，不是单独买的一项服务。

所以分流很清楚：只在浏览器或手机里多开账号、做内容运营，代理更轻；要跑程序、要做中转落地、要把住宅 IP 当基础设施用，VPS 更合适。两者的价格区间其实有重叠，78 元的代理 IP 和 169 元的 VPS 之间差 91 元，差的就是那台机器。

## 常见问题

**住宅 IP 会被平台识别出来吗？**
机房 IP 会被直接识别，因为 ASN 归属就是 IDC。真实住宅 IP 的属性来自运营商分配，平台看到的是家宽用户。风险不在「是不是住宅」，而在「这个 IP 之前有没有被人用坏」。这也是为什么住宅 IP 卖家普遍不敢承诺纯净度。

**静态和动态，我到底该选哪个？**
看你的账号要活多久。长期运营、店铺、流媒体订阅，选静态，IP 固定才能形成稳定的登录画像。一次性注册、数据采集、短期活动，动态更划算，反正用完就换。

**年付版为什么便宜这么多？**
配置缩水换价格。ISP 年付版是 100Mbps、每月 1000GB、10G 硬盘，基础版是 300Mbps、每月 3000GB、20G 硬盘，带宽、流量、硬盘三项都减半以上。年付锁定的是「够用就好」的用户。

**能装 Windows 吗？**
两条线都支持安装 Windows。资料中没有提到是否需要额外的授权费用，下单前建议直接问客服确认。

**一定要中转吗？**
不是必须，但官方建议。部分地区移动、电信直连效果尚可，实际体验因地区和时段而异。稳妥方案是中转加 BBR，尤其在做直播或对延迟敏感的操作时。

**这些套餐能解锁 Netflix、ChatGPT 吗？**
官方宣称支持 TikTok、Claude、ChatGPT、Gemini、Netflix、Disney+、Amazon Prime、Steam、DMM、TVer、Niconico、FOD、Radiko 等服务。注意这是官方声明，不是第三方实测结论，实际表现会随平台策略和 IP 段状态变化，重要业务请先用最小套餐验证。
